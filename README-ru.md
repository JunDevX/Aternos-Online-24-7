## Описание
Этот репозиторий содержит гибридный инструмент автоматизации на **Node.js** и **Python**, который позволяет держать ваш **Aternos Minecraft сервер онлайн 24/7**.  
Система периодически подключается к серверу, предотвращая его автоматическое отключение из‑за неактивности.

## Возможности
- Постоянная работа сервера Aternos 24/7  
- Гибридная архитектура: Node.js — логика, Python — автоматизация  
- Автоматическое переподключение и обработка сессий  
- Модульная структура и простая конфигурация  
- Управление через консоль для быстрого запуска и мониторинга  

## Использование
```
cd NodeJS
npm install
cd ..
cd Python
pip install -r requirements.txt
python gui.py
```
**ИЛИ ДЛЯ NODEJS CLI**
```
cd NodeJS
npm install
node index.js <ip:port вашего атернос сервера> <имя для бота (на английском)> [пароль для регистрации и авторизации (на английском)]
```

## Установка
```bash
git clone https://github.com/JunDevX/Aternos-Online-24-7.git
cd Aternos-Online-24-7
npm install
pip install -r requirements.txt
```
